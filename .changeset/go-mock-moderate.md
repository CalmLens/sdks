`calmlenstest.Options.Moderate` replaces `QueuedOutcome` and `AnalyzedOutcome`: it receives each asset the mock moderates, with its uploaded bytes and text, the trigger (`TriggerUpload`, `TriggerRetry`, `TriggerRerun` or `TriggerComplete`) and whether CalmLens would queue the work, and returns a decision built with `calmlenstest.NewDecision(status)`, whose chained `Flag` and `NotEvaluated` calls fill a complete moderation report and whose invalid categories, qualifiers or scores return `sdk/invalid-argument`. Uploads now record `asset.uploaded`, then `asset.classified` and the automated `asset.<status>`, or `asset.failed`. `mock.CompleteProcessing(assetID, decision)` finishes a processing asset as CalmLens would. `FailNextRequest` replaces `FailNext` and takes `RequestFailure` values with a code or network error, an operation, `Details` and `RetryAfter`, and returns `sdk/invalid-argument` for an unknown code or operation. Captured requests include the HTTP `Status` the mock answered with, and `EnqueueEvent` attaches the asset to an event with a stored asset's ID. A `*calmlens.Error` returned by a custom `HTTPClient` transport is now returned as is.
