`MockCalmLensServerClient.Options.moderate` decides each asset the mock moderates from the stored asset, its uploaded bytes and text, why it is moderated (an upload, a retry, a rerun or `completeProcessing`) and whether CalmLens would queue the work. It returns a `MockDecision`: `MockDecision.of(status)` with `flag(category, score, qualifiers)` and `notEvaluated(category)`, which fills the asset's report with every category, the highest score and the policy's flagged categories. It replaces `queuedOutcome` and `analyzedOutcome`. `completeProcessing(assetId, decision)` finishes processing a pending asset as CalmLens would, and finished uploads record `asset.uploaded`, `asset.classified` and the automated `asset.<status>`, or `asset.failed`. `failNextRequest(failure, FailureOptions)` sets an operation, an API error's `details` and `Retry-After`, fails exactly one request per queued failure and refuses unknown operations; `enqueueRateLimited` is removed. The mock's client makes no retries unless its builder sets `maxRetries`. `decide` refuses `PENDING` and `FAILED`. Recorded requests carry the response `status()` and a `path()` relative to the base URL with decoded segments, and `clearRequests()` forgets them.
