The package includes the `calmlens` CLI, which forwards your project's events to a local webhook handler and creates test events. Run it with `npx calmlens`, or install it with `npm install -g calmlens`: `calmlens` is now published on npm as the same package as `@calmlens/sdk`, at the same version. Standalone executables for macOS, Linux and Windows, and a Homebrew formula, are released in this repository.
