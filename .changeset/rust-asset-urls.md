One URL per asset: every CDN resource is a path beneath it, signed or not.

- `cdn().get_asset_url` returns the asset URL itself, `{cdn_base_url}/assets/{projectId}/{asset}`, when `CdnRequest::resource` is `None`, and a resource URL beneath it otherwise. Name the asset by exactly one of `CdnRequest::asset_id` and `CdnRequest::external_id` (the external ID it was uploaded with, written `ext:` and the URL-encoded ID); `CdnRequest::project_id` defaults to the client's project. `CdnRequest::asset` and `CdnRequest::external` build a request, and `CdnRequest::resource` picks a resource. `asset_identifier` is removed, and a lens or transform without a resource fails with `sdk/invalid-argument`. Viewer claims leave out their defaults: a `region` only when set, which must be a country code, and `age_confirmed` only when true.
- `cdn().sign_asset_url(SignAssetUrlOptions)` replaces `assets().create_signed_url`, `SignedUrlOptions`, `SignedUrl`, `SignedUrlResource` and `SIGNED_CDN_RESOURCES`. It signs a private asset's URL (by `asset_id` or `external_id`) for `expires_in` seconds, from 1 to `MAX_SIGNED_URL_EXPIRES_IN` (24 hours; `DEFAULT_SIGNED_URL_EXPIRES_IN`, 15 minutes, by default), and returns a `SignedAssetUrl` with `url` and `expires_at`. Every resource is served beneath the signed URL; the original only when signed with `original`. `resource`, `lens`, `transform` and `viewer_claims` aren't signed: they are appended as `cdn().get_asset_url` appends them. `MAX_SIGNED_URL_SECONDS` and `DEFAULT_SIGNED_URL_SECONDS` are renamed to `MAX_SIGNED_URL_EXPIRES_IN` and `DEFAULT_SIGNED_URL_EXPIRES_IN`.
- The new `CdnResource::Info` resource and `cdn().get_asset_info(url, GetAssetInfoOptions)` read an asset URL's display info: an `AssetInfo` with the asset's `id`, `project_id`, `asset_type`, `external_url`, `content` (format, size, duration, page count, rendered file, preview and stream) and `availability` (`AssetAvailability::Available`, `AgeRestricted` or `Unavailable`) for the URL's viewer claims, or those the options give. It sends no API key; a refusal fails with the CDN's code, such as `signed-url/expired`. The blocking client offers the same methods.
- `cdn().serve` takes the same asset options; its resource defaults to `CdnResource::Rendered`.
- `ErrorCode::SignedUrlOriginalNotGranted` (`signed-url/original-not-granted`, HTTP 403) is returned for the original beneath a signed URL that doesn't grant it.
- The in-memory mock signs asset URLs beneath its CDN base URL with a readable grant, and its CDN serves them: private assets without the API key until the grant expires, the original only when granted, assets by external ID, and `info`. `MockServerClient::fetch_cdn` fetches a mock CDN URL as a browser would, without the API key. `MockOptions::signed_url_base_url` is removed.
