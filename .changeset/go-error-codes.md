Each API failure has one error code, named resource first, and `Error.Details` tells its cases apart.

- Invalid requests fail with `CodeInvalidRequest` (`validation/invalid-request`); `Details["issues"]` lists each problem's `path`, `message` and issue `code`, such as `CodeTooBig` (`validation/too-big`). `Details["path"]` is gone.
- `CodeUploadTooLarge` (`upload/too-large`, HTTP 413) replaces `CodeFileTooLarge`, `CodeMultipartImageTooLarge` and `CodeUploadPresetTooLarge`, with `Details["limitBytes"]` and `Details["source"]` (`plan` or `preset`). The SDK's own size checks fail with it too.
- `CodeUnsupportedUploadType` (`upload/unsupported-type`, HTTP 415) replaces `CodeInvalidUploadMimeType`, `CodeUploadPresetContentTypeNotAllowed` and `CodeImageUnsupportedFormat`, with `Details["source"]` (`calmlens` or `preset`). The SDK's own type check fails with it too.
- `CodeAssetHeld` (`asset/held`, HTTP 423, `Details["hold"]` `safety` or `copyright`) replaces `CodeAssetSafetyHeld`, `CodeAppealSafetyHeld` and `CodeCopyrightContentHeld`; `CodeImageTooLarge` (`image/too-large`, `Details["limit"]`) replaces `CodeImageInputLimit` and `CodeImageExceededMaxDimensions`; `CodePermissionDenied` (`auth/permission-denied`, `Details["permission"]`) replaces `CodeDownloadPermissionRequired`.
- Renamed codes: `api-key/invalid`, `api-key/missing`, `api-key/project-mismatch`, `api-key/not-accepted`, `session-token/expired`, `session-token/invalid`, `cursor/invalid`, `filter/invalid`, `ordering/unsupported-field`, `request/unsupported-content-type`, `request/route-not-found`, `server/internal-error`, `viewer-claims/invalid`, `viewer-region/invalid`, `transform/invalid`, `transform-options/invalid`, `upload-payload/invalid`, `upload-part/invalid-number`, `image/invalid`, `hash-list-entry/not-found`, `hash-list-entry/limit-reached`, `support-ticket/not-found`, `upload/website-rate-limit-reached`, `remote-url/not-allowed`, `remote-url/invalid`, `remote-url/unavailable` and `remote-url/too-many-redirects`. Usage limits fail with `usage/free-uploads-exhausted` and `usage/uploads-paused`.
- Constant names follow: `CodeMissingAPIKey`, `CodeInvalidImage`, `CodeFreeUploadsExhausted`, `CodeUploadsPaused`, `CodeUnsupportedOrderingField`, `CodeWebsiteRateLimitReached` and `CodeRemoteURLTooManyRedirects` replace `CodeMissingToken`, `CodeImageInvalidInput`, `CodeUploadLimitExceeded`, `CodeSpendLimitReached`, `CodeInvalidOrderingField`, `CodeWebsiteRateLimitExceeded` and `CodeRemoteURLRedirectLimit`.
- The `calmlenstest` mock answers with the same codes and details.
