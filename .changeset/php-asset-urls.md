One URL per asset: every CDN resource is a path beneath it, signed or not.

- `$client->cdn->getAssetUrl([...])` returns the asset URL itself, `{cdnBaseUrl}/assets/{projectId}/{asset}`, when no `resource` is given, and a resource URL beneath it otherwise. Name the asset by exactly one of `assetId` and `externalId` (the external ID it was uploaded with, written `ext:` and the URL-encoded ID); `projectId` defaults to the client's project. `assetIdentifier` is removed, and a `lens` or `transform` without a resource fails with `sdk/invalid-argument`. Viewer claims leave out their defaults: a `region` only when set, which must be a country code, and `ageConfirmed` only when true.
- `$client->cdn->signAssetUrl([...])` replaces `$client->assets->createSignedUrl`. It signs a private asset's URL (by `assetId` or `externalId`, with an optional `projectId`) for `expiresIn` seconds, from 1 to `Cdn::MAX_SIGNED_URL_EXPIRES_IN` (24 hours; `Cdn::DEFAULT_SIGNED_URL_EXPIRES_IN`, 15 minutes, when omitted), and returns `['url' => ..., 'expiresAt' => ...]`. Every resource is served beneath the signed URL; the original only when signed with `'original' => true`. `resource`, `lens`, `transform` and `viewerClaims` aren't signed: they are appended as `getAssetUrl` appends them. `Assets::MAX_SIGNED_URL_SECONDS` and `Assets::DEFAULT_SIGNED_URL_SECONDS` are removed.
- The new `info` resource and `$client->cdn->getAssetInfo($url, ['viewerClaims' => ...])` read an asset URL's display info: the asset's `id`, `projectId`, `type`, `externalUrl`, `content` (format, size, duration, page count, rendered file, preview and stream) and `availability` (`Cdn::AVAILABILITY_AVAILABLE`, `Cdn::AVAILABILITY_AGE_RESTRICTED` or `Cdn::AVAILABILITY_UNAVAILABLE`) for the URL's viewer claims, or those the options give. It sends no API key; a refusal throws the CDN's code, such as `signed-url/expired`.
- `$client->cdn->serve([...])` takes the same asset options; its resource defaults to `rendered`. `Cdn::RESOURCES` lists every resource, `info` included, and `Cdn::SELECTABLE_RESOURCES` those that take a lens or transform.
- `ErrorCodes::SIGNED_URL_ORIGINAL_NOT_GRANTED` (`signed-url/original-not-granted`, HTTP 403) is returned for the original beneath a signed URL that doesn't grant it.
- `MockServerClient` signs asset URLs beneath its CDN base URL with a readable grant, and its CDN serves them: private assets without the API key until the grant expires, the original only when granted, assets by external ID, and `info`. `MockServerClient::fetchCdn($url)` fetches a mock CDN URL as a browser would, without the API key.
