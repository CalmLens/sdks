`ServerClient` takes `maxResponseBytes` (32 MiB by default) and `uploadTimeout` (seconds per binary upload attempt; none by default), also accepted in `requestOptions`, and its defaults are constants on `ServerClient`. A response whose declared `Content-Length` exceeds `maxResponseBytes` fails with `sdk/response-too-large` before its body is read. Retries now wait half the exponential backoff plus a random part of the other half; `Retry-After: 0` retries at once, `cdn->serve` retries like other reads and returns the last response, and timeouts are retried. A redirect fails with `sdk/http-error`, its status and request ID, `cdn->serve` included, and is never followed or retried. Transport errors no longer carry `details['network']`, and API errors carry only the API's details and `traceId`. Uploads answered with something other than an asset fail with `sdk/invalid-response`. A non-seekable file stream may leave out `sizeInBytes`. The API, not the client, now checks idempotency key characters, so those failures carry the API's code and status; like every HTTP request, a key is sent without surrounding whitespace. `assets->each`, `eachChild` and `events->eachPage` stop at an empty asset page and fail with `sdk/invalid-response` (with `details['cursor']`) without yielding a page that repeats a cursor already sent. `waitForDecision` polls with the client's usual retries and request deadline. Webhook helpers join repeated signature headers with `,`, and `parseEvent` checks the types of known `data` fields. The User-Agent now names the PHP runtime. `MockServerClient` adds `setApiKeyGrants`, `signUploadToken` for exact tokens at a fixed clock and nonce, and `failNextRequest` with an API error code and a client method to target; it records `asset.deleted`, `asset.content-removed` and `asset.retried` events, serves a ThumbHash placeholder PNG for classified images, sets the CDN's `Cache-Tag`, protection headers, `ETag` and `Expires`, returns `null` for unset fields, checks multipart parts in the API's order, scopes list cursors to their query, and refuses out-of-range page sizes, search limits and event limits with `validation/*` codes and `details['path']`. A reviewer's purge removes the content with reason `requested`.
