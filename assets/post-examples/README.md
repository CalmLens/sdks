# Shared example-post artwork

These photo and illustration images are the maintained source for both the landing moderation feed and Calmgram.
Both builds copy them into `/post-examples/`; the shared catalogue selects each illustration.

Use a verified openly licensed photograph for ordinary real-world subjects when appropriate;
record its source and licence in PHOTOS.md, and serve an optimized local WebP. Use illustrations
for abstract media and sensitive examples. Draw illustrations with rounded forms and plain
backgrounds. Use a complementary editorial palette, separate from the interface colours: sage and tomato
for gardens, warm wheat for baking, dusty blue landscapes, clay, cream and muted teal.
Do not reuse CalmLens’s exact primary purple or UI theme tokens. Avoid dotted backgrounds, product
cards, dashboard frames, gradients, screenshots and generic SaaS diagrams. Keep harmful content
censored and let the consumer hide rejected examples. These are static image assets, not inline
SVG markup in each repeated post.
